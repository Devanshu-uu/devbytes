# ✨ About DevBytes

**DevBytes** is my personal portfolio where I showcase my work, projects, skills, and learning journey as a developer.

The goal wasn't just to build another portfolio.

I wanted to create something that feels modern, smooth, responsive, and enjoyable to explore.

Whether you're browsing my projects, reading my blog, or getting in touch, every section is designed with simplicity and performance in mind.
