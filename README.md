## ✨ Key Features Built In

> 📱 **Fully Responsive Layout** — Fits beautifully on ultra-wide monitors, tablets, and tiny mobile viewports.
> ✍️ **Markdown-Powered Blog** — Integrated seamlessly with `react-markdown` to load content dynamically.
> 🎵 **Custom Music Player** — An immersive, unique music element built straight into the site components.
> 📚 **Showcase Hub** — Modular custom sections highlighting Projects, Skills, Certificates, and Education.

## 📂 Project Architecture

Here is a look inside the directories configuring this Single Page Application:

```text
├── public/             # Static graphics and icons
├── src/
│   ├── api/            # API integration models
│   ├── components/     # Reusable UI layout blocks
│   │   ├── About.jsx
│   │   ├── BlogSection.jsx
│   │   ├── Certificates.jsx
│   │   ├── Contact.jsx
│   │   ├── Education.jsx
│   │   ├── Footer.jsx
│   │   ├── Hero.jsx
│   │   ├── MusicPlayer.jsx
│   │   ├── Navbar.jsx
│   │   ├── Projects.jsx
│   │   ├── Skills.jsx
│   │   └── Socials.jsx
│   ├── hooks/          # Custom React hooks
│   ├── lib/            # Configuration files & libraries
│   ├── pages/          # Parent page route structures
│   ├── utils/          # Global application helper utilities
│   ├── App.jsx         # Global router and entry views
│   ├── main.jsx        # Project React DOM renderer
│   ├── PageNotFound.jsx
│   └── index.css       # Core styling & design rules
├── tailwind.config.js
├── vercel.json         # Routing deployment configurations
└── package.json
